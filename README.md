# Pelorus Production Website

Welcome to the **Pelorus Production** portfolio website! This React-based website, built with Vite, showcases the company's work and provides an easy way for potential clients to get in touch.

## Features

- 🎥 **Portfolio Showcase** – Display high-quality projects and past work.
- 📩 **Contact Form** – Easily collect inquiries from visitors.
- ⚡ **Fast Performance** – Optimized with Vite for speed and efficiency.
- 🎨 **Modern UI/UX** – Clean, responsive design for a seamless experience.

## Technologies Used

- **Frontend:** React, Vite, React Router
- **Styling:**  Styled Components


## Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/pelorus-production.git
   cd pelorus-production
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview the production build:**
   ```bash
   npm run preview
   ```
